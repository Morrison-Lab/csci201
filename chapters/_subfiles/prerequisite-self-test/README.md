# Prerequisite self-test subfiles

These are the units of `chapters/prerequisite-self-test.qmd`,
one exercise or solution div per file.

The self-test is ungraded, so its answers are public
([mcs#167](https://github.com/Morrison-Lab/mcs/issues/167)).
Keep its items different from the graded week-1 Quiz 0,
which covers the same topics,
so that publishing these answers gives none of that quiz away.

Keep this note here rather than in an HTML comment on the page:
a comment on the page reaches the published HTML,
and students must not see where the graded work lives.
